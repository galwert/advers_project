# Pairwise Representational Similarity Matrices (20 LLMs)

Five 20×20 pairwise similarity matrices computed at the 50%-depth target layer
on harmful prompts (AdvBench). These power `tab:family_corr`, `tab:matrix_ve`,
`tab:matrix_rsa`, and Figure 1 (left) in the paper.

## Files

| File                            | Metric            | Range  | Backs                              |
|---------------------------------|-------------------|--------|------------------------------------|
| `cka_harm_pct50.json`           | Linear CKA (harm) | [0,1]  | `tab:family_corr` row 1; `fig:bar_transfer` (right) bins |
| `rsa_harm_pct50.json`           | RSA (harm)        | [0,1]  | `tab:family_corr` row 3; `tab:matrix_rsa`; Figure 1 left |
| `var_explained_pct50.json`      | Variance Explained | [0,1] | `tab:family_corr` row 2; `tab:matrix_ve` |
| `distance_ratio_pct50.json`     | Distance Ratio    | [0,1]  | `tab:family_corr` row 4 |
| `neighborhood_harm_pct50.json`  | Neighborhood overlap | [0,1] | Background metric in `app:similarity_metrics` |

JSON files use pandas split-orient format (`{"columns": [...], "index": [...], "data": [[...]]}`); load with
`pd.read_json(path, orient="split")`. All matrices are symmetric with diagonal = 1.0 (self-similarity).
Rows and columns are indexed by short model name (e.g. `mistral`, `llama3`,
`qwen`, …); see `app:family_inclusion` in the paper for the full pool.

## Reproducing Figure 1 from these matrices

```bash
# Heatmap (Figure 1 left)
python scripts/regen_heatmap.py
# -> figs/heatmap_rsa_harm_clustered.{png,pdf}

# Bar chart (Figure 1 right) — pulls cross-layer CKA from data/cross_layer_cka/
python scripts/regen_bar.py
# -> figs/bar_final.{png,pdf}
```

## Source

Generated by the geometry-extraction pipeline in the development tree
(`phase1/`); the values match the canonical artifacts bit-for-bit (CSV
sources converted to JSON via pandas to_json with orient='split') and are
released here so reviewers can reproduce the figures without rerunning the
(compute-heavy) hidden-state extraction step.
